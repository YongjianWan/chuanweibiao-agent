# 项目特征摘要

本项目为济阳区实验高级中学项目工程总承包（EPC），位于济南市济阳区，招标人为济阳区教育和体育局。总建筑面积约 10.01 万㎡，框架结构，Ⅰ类工程，合同估算价 5.8 亿元，财政投资 100%。

工程为教育类公共建筑群，含教学楼、宿舍楼、综合楼、餐厅、艺体楼、地下车库及操场，单体多、功能分区多、专业交叉密集。计划工期 1020 日历天（2026-08-30 至 2029-06-15），质量要求合格；EPC 范围含设计（深化设计与施工图）、采购、施工、调试、验收、移交、保修全过程。

结构安全等级一级，抗震设防 7 度（0.15g）、按 8 度采取抗震措施，场地类别 Ⅲ 类、重点设防类（乙类）；含地下室与地下车库，地下防水等级 Ⅰ 级。

招标文件点名的重点：装配式建筑与绿色建筑、智慧工地（Ⅲ 星级）要求；地下车库覆土顶板质量安全（济建发〔2020〕44 号）为地方明文重点；临近教学区，对安全、防尘、文明施工要求高。

地质水文：招标文件未提供具体地质水文数据，明确「签订合同时另行协商」，投标文件须自行说明现场勘察与地质条件的充分性。
